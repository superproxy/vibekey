# 型号 arn9

L1 公共键位。空槽=保留；不继承全局。

| 键 | 触发 | 动作 |
| --- | --- | --- |
| 上 | 单击 | wheel up |
| 下 | 单击 | wheel down |
| 返回 | 单击 | Esc |
| 主页 | 单击 | Alt+Tab（公共默认） |
| 主页 | 长按 / 双击 | 公共保留；全局应用层：单击=Win+Tab 任务视图，长按=上一窗，双击=下一窗 |
| 确认 | 单击 | Enter |
| 确认 | 长按 | 保留（Cursor 应用层覆盖为 Ctrl+Enter 提交） |
| 语音 | 单击 | Win+H（再按再发，开关录音） |
| 音量/电源 | 全部 | 保留 |

| 项 | 处理 |
| --- | --- |
| TV | 无则不适用 |
| 语音 | 映射程序不支持 BLE 录音 → AxonKey 内 Win+H |
