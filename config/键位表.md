# vibekey v1 键位配置

适用：Windows 上的 AxonKey 1.9.6，小米蓝牙遥控器 2 Pro（RC003）。

这是一份可复用的键位约定，不是 AxonKey 官方可导入备份。请用官方 CLI（`mapping set` 等）按自己的设备实例和配置名称写入。空槽位表示保留遥控器原输入，不会自动继承全局配置，所以公共习惯要在每一份应用配置里都写一遍。

按应用自动切换打开后，把对应软件点到前台，就会用那一份配置；未绑定的软件走全局配置。

应用绑定请使用 AxonKey 在你这台机器上实际观察到的应用 ID，不要照抄别人的本机路径或配置 UUID。

## 公共习惯（每一份配置都要写入）

| 按键 | 触发 | 动作 |
| --- | --- | --- |
| 上 | 单击 | 滚轮向上 |
| 下 | 单击 | 滚轮向下 |
| 返回 | 单击 | Esc（Chrome 配置除外，见下表） |
| 主页 | 单击 | Alt+Tab，切到上一个应用 |
| 确认 | 单击 | Enter。聊天里可能发送，终端有焦点时可能执行命令 |
| 语音 / 音量加 / 音量减 | 全部 | 保留原输入 |
| 电源 / TV | 全部 | 保留，不映射关机或其他危险操作 |
| 确认 | 长按 | 保留，不设 Enter |

未写出的双击、长按一律保留原输入。上下滚轮跟鼠标指针位置有关，滚的是指针下面的区域，不一定是键盘焦点。

## 各配置差异

| 按键 | 触发 | 全局 | Grok Bot | WorkBuddy | 企业微信 | Chrome |
| --- | --- | --- | --- | --- | --- | --- |
| 返回 | 单击 | Esc | 同全局 | 同全局 | 同全局 | 浏览器后退 Alt+Left（Chrome 官方默认） |
| 菜单 | 单击 | 保留 | 保留 | Ctrl+K 搜索（WorkBuddy 官方默认） | Ctrl+Alt+F 搜索（企业微信官方默认） | 聚焦地址栏 Ctrl+L（Chrome 官方默认） |
| 左 | 单击 | 保留 | 上一个 Bot Alt+Up（Grok Bot 官方默认） | 上一任务 Ctrl+[（WorkBuddy 官方默认） | 保留 | 上一标签 Ctrl+Shift+Tab（Chrome 官方默认） |
| 右 | 单击 | 保留 | 下一个 Bot Alt+Down（Grok Bot 官方默认） | 下一任务 Ctrl+]（WorkBuddy 官方默认） | 保留 | 下一标签 Ctrl+Tab（Chrome 官方默认） |

应用绑定建议（名称以 AxonKey 观察到的为准）：

- 快意编程v1-Grok Bot → Grok Bot
- 快意编程v1-WorkBuddy → WorkBuddy
- 快意编程v1-企业微信 → 企业微信 / WXWork
- 快意编程v1-Chrome → Google Chrome

## Cursor（拟定，尚未写入）

要先把 Cursor 点到前台，让 AxonKey 观察到真实应用 ID 后再创建并绑定。不要猜测应用 ID。

| 按键 | 触发 | 拟定动作 | 依据 |
| --- | --- | --- | --- |
| 上 / 下 | 单击 | 滚轮上 / 下 | 公共习惯 |
| 返回 | 单击 | Esc | 公共习惯 |
| 主页 | 单击 | Alt+Tab | 公共习惯 |
| 确认 | 单击 | Enter | 公共习惯。聊天可能发送，终端有焦点时可能执行命令 |
| 菜单 | 单击 | Ctrl+P 快速打开文件 | Cursor 官方默认（与 VS Code 一致） |
| 菜单 | 长按 | Ctrl+I 打开或聚焦 AI 面板 | Cursor 官方默认 Open Chat |
| 左 / 右 | 单击 | Ctrl+PageUp / Ctrl+PageDown，切编辑器标签 | Cursor / VS Code 默认切编辑器标签，不是切 AI 会话 |
| 语音 / 音量 / 电源 / TV | 全部 | 与公共习惯相同 | 公共习惯 |

未纳入：自动发送提示词、accept all、批准命令、删除、执行终端命令等危险宏。也没有编造「全局切 AI 会话」的快捷键。

## 已知限制

- 语音键需要按住，AxonKey 才会把声音转到虚拟麦克风；短按不会开始应用里的录音。
- 主页键的 Alt+Tab 是一次完整按下再松开，窗口列表通常不会停住。双击改成 Ctrl+Alt+Tab 可以打开能停留的切换面板，这一项尚未写入，也不适合放在长按上（会重复触发）。
- `profile create` 可能会把当前全局激活配置切到新建立的那一份，批量创建后要记着切回去。
- 应用内快捷键若被用户改过，上表中的「官方默认」会不准，需要按本机实际快捷键调整。
- 这套键位按语义回读核对过，不代表已经完成真人手感验收。
